# Behavioral Profile

Optional. How the candidate works, and how to use it in documents and interviews. The facts
behind it (traits, reviews, evaluations) live in 01's "Behavioral summary" and "References".
Read by `04-job-evaluation.md` (culture fit), the cover letter skill and the interview skill.

This file starts empty. The `onboard` skill fills it. Write "none" where nothing applies.

## Assessment

What goes here: the name, date and main results of any formal assessment the candidate has
(for example DISC, MBTI, CliftonStrengths, Predictive Index, a manager's written evaluation).
If there is none, write "none", and no document may cite one.

## Work style

What goes here: how the candidate likes to work, in their own words. For example: alone or in a
team, with clear tasks or open problems, fast or careful, remote or in person, how they handle a
vague task.

## Strengths

What goes here: the two to four strengths to lead with, each tied to a Story in 01.

## Growth areas (internal)

What goes here: honest weak points, for fit checks and interview prep only. Never in a document.

## Posting language

What goes here: phrases in a posting that signal a strong fit (for example "end-to-end
ownership", "small team"), and phrases that signal friction (for example "large matrixed
organisation"). Friction lowers the culture score; it is not a gate. Gates live in 01's
Constraints.

## Using this

What goes here: how each document uses the profile. Defaults:
- **Letters:** lead with the strongest trait, shown by one real case.
- **CV:** results, tools and numbers; traits only through what was done.
- **Interviews:** match the candidate's natural way of speaking.
- **Never claim:** (traits or roles the evidence does not support, for example "team lead")
